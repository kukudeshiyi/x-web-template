# X1 UI 重构计划

## 说明

这份文件用于承接 `x1` 在基础层准备完成之后的 UI 重构实施计划。

约束：

- 不修改 `x1` 的核心 SEO 资产设计原则
- 所有改动必须持续通过 `cd x1 && yarn test`
- UI 参考 `luno-mirror`，但实现要基于当前 `x1` 架构
- 这份文件只讨论 UI 重构，不重复记录已经完成的前置基础层工作

## 目标

1. 重构页面框架
2. 重构首页
3. 重构文章详情页
4. 落地 tag 页面最终 UI
5. 落地 author 页面最终 UI
6. 视需要评估并落地 contact 页面

## 实施边界

已完成的基础层能力：

- 统一配置真源
- locale 配置收口
- 文章 frontmatter 契约
- 编译期 TOC 提取
- 统一内容查询层
- 静态搜索索引
- tag / author 路由基础层

本文件后续重点规划：

- 页面信息架构
- UI 组件拆分
- 页面分阶段改造顺序
- 响应式与动效要求
- 每个阶段的验证方式
